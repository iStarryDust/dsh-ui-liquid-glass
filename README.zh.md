# 液态玻璃 · DeepSeek Harness 皮肤插件

给 DSH Web 界面加一层可调的液态玻璃材质。侧边栏、对话区、右侧栏、页面、输入栏、会话头、设置菜单都换成
玻璃；页面背景换成随时段自动轮换的壁纸；右下角一个小太阳按钮打开控制面板。

所有玻璃面都由同一条契约生成（位移贴图 → 模糊 → 对比度 → 亮度 → 饱和度 → 边缘），所以任何一层在任何
数值上都与样本胶囊是同一种材质。

## 有什么

- **12 个可调玻璃区域** —— 侧边栏、对话区、右侧栏、栏内整页、输入栏、提问卡、会话头、选中
  高亮、新会话行、输入控件、弹窗菜单，以及可拖拽的样本胶囊。
- **每层 14 根拉条** —— 色调、色调饱和度、浓度、模糊、对比度、亮度、饱和度、边缘强度、位移幅度、色散
  等。每根都真的驱动一个量，没有拉不动的死拉条。
- **时光壁纸** —— 三张随包图按时段切换（04:00–11:59 / 12:00–17:59 / 18:00–03:59），每 30 秒复查一次。
  另外四张作为普通壁纸随包：点一下固定、可删除，也可以上传自己的图（上传与删除会写磁盘）。
- **四档主题色** —— 官方 DeepSeek 蓝（默认）、金色、纯白、高雅黑。同时作用于壳层主色阶与新会话层。
- **选中高亮** —— 当前激活的侧栏行或设置导航格带玻璃；切换时一块透镜从旧位飞到新位（弹簧、拉伸、拖尾）。
- **浓度随亮暗** —— 七个大面层的浓度与亮度跟随亮暗自动切换，浅色主题不会糊上一层重色。
- **随包字体** —— HarmonyOS Sans SC 三档，由插件直接供图并以 `--dsw-font-family` 发布；不装进系统，
  卸载即消失。

## 安装

```sh
dsh plugin add @istarry/dsh-ui-liquid-glass
```

装完重启 DSH 服务（桌面端完全退出再打开，或重启 `dsh web`）。

## 使用

点右下角小太阳：

- **主题** —— 壁纸、主题色、文字颜色。
- **控件** —— 每个区域一个页签，各 14 根拉条，外加共享的样本胶囊。

所有数值自动保存，每页有单页重置，也有整体重置。

## 权限与行为

装之前请读这一段 —— 它不是一个被动的样式表：

- **会写磁盘。** 首次激活时创建 `~/.dsh/ui-liquid-glass/wallpapers` 并播入随包壁纸，**只补缺失、从不
  覆盖**你已有的文件。`Default/` 子目录与随包轮换集保持同步并会被清理；该目录的**根目录归你**，从不清理。
- **会注册 HTTP 路由**（挂在宿主 Web 服务上）：`GET /ui-liquid-glass/wallpapers`（列表）、
  `GET /ui-liquid-glass/wallpapers/<文件名>`（图片字节）、同路径的 `POST` / `DELETE`（添加 / 删除）、
  以及 `GET /ui-liquid-glass/fonts/<文件>`（随包字体）。没有 Web 服务的端（桌面壳）这些路由不会就绪，
  此时壁纸选择器会隐藏上传 / 删除。
- **会覆盖宿主 CSS 变量。** 发布 `--lg-*`，重映射部分官方 `--dsw-*`（背景、菜单层、悬停底色），并设置
  `--dsw-font-family`。全部作用域在 `body[data-lg-skin]` 下，卸载插件即恢复官方外观。
- **本地偏好存在 localStorage** 的 `ui-liquid-glass/skin/v4`（仅浏览器端）。

## 兼容性

- 实测于 DSH `0.2.0-rc.2`。
- peer 依赖：`@deepseek-ai/cordis` `^4.0.1`。
- 浏览器半端是自包含 bundle，不声明 `dsh.client.inject`；只挂官方 CSS 变量、官方布局 local 名与 ARIA 角色。

## 从源码构建

仓库已提交预构建的 `lib/`，所以从仓库安装**不会触发构建**。本地重建需要一份 DSH 源码检出——
`tsconfig.json` 继承宿主的 `tsconfig.base.client.json`，`tsdown.config.ts` 引用宿主的 client 预设：

```sh
pnpm install
pnpm exec tsc -b .
pnpm exec tsdown
```

`tsdown.config.ts` 里的包名会被写进产物（`window.__ModuleLoader__.load({ id })`）——改名必须改这里并重建。
